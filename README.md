# Кварта — лендинг минской обжарки

Локальный лендинг и endpoint заявок. Для запуска: `python main.py`, затем откройте `http://localhost:8000`.

## Что внутри

- Адаптивный лендинг на русском языке: ассортимент, цены, подписка, доставка, самовывоз и форма.
- Логотип — собственная типографическая буква «к» в круге; отрисовывается HTML/CSS без сторонних скриптов.
- Для текста используются Golos Text и PT Serif; системные шрифты остаются резервом. Страница отдаёт HTML, CSS, JS и SVG с gzip при поддержке браузера, а версионные статические файлы кэшируются. Фото запрашиваются адаптивного размера и пониженного качества; второстепенные изображения загружаются по мере прокрутки.
- `POST /api/lead` принимает имя, белорусский телефон, тип интереса и комментарий.
- Заявки сохраняются в SQLite и приходят в Telegram карточками. Кнопки позволяют позвонить, добавить заявку в заказы, отклонить её, записать заметку и поставить напоминание. Контактная карточка клиенту не отправляется.
- «В работу» создаёт заказ в отдельной таблице `orders`. Команда `/leads` показывает новые заявки, заказы в работе и активные напоминания. Заметки звонков хранятся в `lead_notes`; напоминания — в `lead_reminders`.
- Напоминания принимают `18.10.2026 14:30`, `18.10 14:30`, `завтра 10:00`, `послезавтра 15:30` и `через 2 часа` (в локальном часовом поясе сервера). По наступлении времени бот присылает напоминание с кнопками открыть карточку и закрыть напоминание.
- Токен хранится только в игнорируемом `.env`; пример настроек — `.env.example`.
- Чтобы подключить получателя, запустите бота и отправьте ему `/start` от аккаунта `@wxnasleep`. Telegram не разрешает боту первым писать пользователю по имени; после `/start` накопленные заявки отправятся автоматически.
- Telegram long polling работает внутри процесса `main.py`. Если бот уже использует webhook или другие обработчики обновлений, polling нужно вынести/согласовать с ними.
- Телефон приводится к формату `+375…`; API проверяет белорусский код оператора.
- SQLite хранит заявки в `leads.sqlite3` рядом с приложением. Это компактный вариант без внешнего сервиса: заявки сохраняются после перезапуска, их можно выгрузить или передать CRM. Файл базы включён в `.gitignore`.
- В таблице есть рекламные метки `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, адрес страницы и referrer.
- Повтор того же нормализованного номера в течение 10 минут возвращает подтверждение без создания второй записи. Проверка и вставка защищены транзакцией SQLite, поэтому двойное нажатие или параллельные запросы не обходят ограничение.
- Клиентская форма блокирует повтор того же номера на этой вкладке и показывает ошибки сети с предложением повторить отправку. Серверная проверка остаётся основной.
- Серверная защита заявок ограничивает IP до 6 запросов за 10 минут и 30 за сутки; IP хранится только как HMAC-хеш. Есть лимит размера тела, короткий тайм-аут чтения, проверка формата и скрытое поле-ловушка. Одновременно обслуживается не более 48 запросов.
- Это ограничение на уровне приложения: при публикации за reverse proxy нужно включить rate limiting и сетевую защиту на proxy/CDN.
- Форма использует стилизованный доступный список интересов; на мобильных экранах сетка перестраивается в отдельную компактную раскладку.
- Карта по умолчанию — Яндекс Карты; посетитель может переключить встроенную карту на Google Maps.

## Допущения

- Если Telegram временно недоступен, заявка остаётся в SQLite со статусом ожидания отправки; повторная доставка выполняется после подключения получателя командой `/start`.
- Указанный в макете телефон `+375 (29) 123-45-67` — пример из ТЗ, его нужно заменить реальным номером до публикации.
- Для фотографий используются изображения Unsplash по URL. Перед публичным запуском стоит закрепить подходящие файлы с подтверждённой лицензией и проверить доступность загрузки.
- В блоке знакомства стоит единая иллюстративная фотография пары из Unsplash: https://unsplash.com/photos/two-cafe-owners-proudly-stand-together-dU3KJqyYlO0. Это не настоящие основатели «Кварты»; перед публикацией желательно заменить её фотографией владельцев.
- Форма принимает белорусские мобильные коды 25, 29, 33, 44 и 17; формат `+375` и локальный формат с нулём нормализуются автоматически.
- Текущий адрес обжарки — ул. Короля, 9, как указано в ТЗ. Встроенные карты и ссылки ведут на координаты 53.902241, 27.542023.

## Что сделано в ходе работы

С нуля собраны визуальная концепция и интерфейс, написан Python endpoint, клиентская валидация и сохранение рекламной атрибуции. В качестве визуальных ориентиров изучены редакционные сайты обжарщиков и примеры небольших coffee roastery one-page: короткий каталог, происхождение кофе, фокус на свежести и отдельный путь к подписке. Уникальная деталь концепции — календарная шкала партии «четверг → пятница → чашка», связанная с реальным графиком обжарки из задания.

Сайт собран без генератора: структура и стили сверстаны вручную. Внешние изображения и веб-шрифты подключаются из интернета; без сети остаются системные резервные шрифты, а фотографии могут не загрузиться. Бэкенд и сама страница при этом локальные.

## Перед публикацией

Подключить рабочий номер, проверить конечный хостинг и базу на постоянном диске, добавить политику обработки персональных данных и реальный канал передачи заявок сотруднику. В исходном ТЗ эти данные отсутствуют. Также понадобятся репозиторий, публичный хостинг и мобильный Lighthouse-отчёт, чтобы закрыть требования к финальной сдаче.
