# Кварта — кофейная мастерская

Одностраничный сайт минской обжарки с каталогом кофе, формой заявки, картой и компактной мобильной раскладкой. Сервер на Python сохраняет заявки в SQLite и передаёт их в Telegram; оператор может вести заказ, оставлять заметки и ставить напоминания.

## Запуск

Нужен Python 3.10+. Скопируйте `.env.example` в `.env`, заполните токен бота и запустите `python main.py`. Сайт откроется на `http://localhost:8000`. Для локальной базы используется `leads.sqlite3`; реальные секреты и база в Git не попадают.

## Замер и ограничения

[`reports/lighthouse-mobile.report.html`](reports/lighthouse-mobile.report.html) и JSON — локальный мобильный Lighthouse для `localhost:8000`, снятый 14.10.2026 в Edge. Оценки: производительность 90, доступность 96, практики 100, SEO 100. Это один лабораторный запуск, не гарантия показателей на каждом телефоне или сети.

До публикации нужно заменить примерный телефон, добавить политику обработки персональных данных и проверить Telegram-бота на отдельном рабочем окружении. Текущие владельцы на фото — иллюстрация, не подтверждённые реальные владельцы мастерской.
